# DUYG 独小漾｜服装研发多模态 Agent 与能力协同平台

重庆独小漾服饰有限公司｜AI 应用开发实习生｜2026.06—至今

## 项目介绍

面向服装研发、美编及运营团队建设企业 AI 工作台，整合知识检索、服装图像编辑与门店数据分析，以自然语言调度模型、工具和业务工作流。平台已供 78 名员工使用，帮助美编将出图耗时由 220 秒缩短至 72 秒，降幅约 67%，并为运营问题定位与整改提供分析依据。

## 技术架构

采用“主 Agent 编排层＋独立能力中枢＋隔离执行层”的分层架构。FastAPI 与 LangGraph 承担任务路由和工具调用；能力中枢聚合 Skill、MCP 与 ComfyUI 工作流。知识链路串联 OCR、结构化分段、关键词/向量混合召回与重排；执行层对接 ComfyUI 异步任务与 Docker 代码沙箱，通过 MySQL、Redis、文件存储及 SSE 衔接状态持久化、产物归档和过程反馈。

## 我的职责

**企业 RAG 建设与评测：**负责知识入库、结构化分段及混合检索链路，针对工艺文档、制度条款和表格保留标题层级与表头上下文，接入重排与来源追踪。在管理员多空间合并检索评测中，150 道自然题 Hit@5 达 93.3%（140/150），650 道分层题达 82.2%（534/650）；推进身份与部门范围过滤，并通过越权用例定位通道覆盖缺口。

**ComfyUI 工作流工程化：**负责 Agent 与 ComfyUI 的端到端集成，将服装部位、编辑意图及遮罩参数组织为结构化改款计划，接入工作流目录；实现异步提交、状态轮询、任务取消与结果归档，并校验任务归属。优化美编出图流程，将耗时由 220 秒缩短至 72 秒。

**沙箱执行治理：**负责 Docker 沙箱的执行隔离与资源治理，配置非特权、默认禁网及 CPU、内存、进程数和超时限制；实现路径校验、产物大小限制与执行账本，区分代码执行状态和产物提交状态，以哈希与提交回执支持异常核对，为表格处理和门店数据分析提供受控环境。

**主 Agent 与能力中枢：**负责 Skill、MCP 工具与工作流统一聚合，建设能力目录、按需加载和统一调用接口，将模型决策与具体执行解耦；接入参数校验、服务端授权、执行审批及配置指纹校验，通过执行回执追踪调用结果，支持能力扩展与复用。
